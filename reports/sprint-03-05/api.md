# API реализованного каталога

Все маршруты находятся на том же сервере, что и интерфейс. Авторизация для просмотра каталога не требуется. Изменение товаров, покупки и скачивание оплаченных комплектов пока не реализованы.

| Запрос | Результат |
| --- | --- |
| `GET /api/health` | Состояние соединения и фактическая версия PostgreSQL; 503 при недоступности БД. |
| `GET /api/products` | `{items: Product[], total: number}`. Только опубликованные товары с обложкой, демо и полным набором вариантов. |
| `GET /api/products?q=night&type=beat` | Поиск подстроки названия и необязательный тип `beat` / `drumkit`. Поиск без учёта регистра, NFC; SQL-символы считаются обычным текстом. Максимум 140 символов запроса. |
| `GET /api/products/:slug` | Один товар; 404 для отсутствующего, скрытого или неполного товара. |
| `GET /api/media/:uuid` | Текущая публичная обложка или демо опубликованного полного товара. Аудио поддерживает Range / 206. Основной файл, чужой тип и неизвестный UUID возвращают 404. |

Product содержит `id`, `slug`, `title`, `description`, `type`, `genre`, `bpm`, `musicalKey`, `coverUrl`, `demoUrl`, `variants`. Вариант содержит `kind`, `label`, `bundle`, точную десятичную строку `price` и `currency: "RUB"`. Идентификаторы основных файлов, ключи хранилища, SHA-256 и версии шаблонов в публичные ответы не включаются.

Некорректная форма параметров — 400, неизвестный API-маршрут — 404, внутренняя ошибка — 503 с общим сообщением. Пользователь не получает SQL, путь файла или реквизиты соединения. Сервер не раздаёт корневой каталог проекта и `.local`. Системный путь файла определяется по записи в БД и проверяется после realpath относительно корня хранилища.

Проверки API выполняют реальные HTTP-запросы к Express и SQL-запросы к отдельной временной схеме PostgreSQL. Рабочий каталог не изменяется.
