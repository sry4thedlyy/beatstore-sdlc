# Beatstore

Учебный проект по дисциплине «Технологии создания и поддержки программного обеспечения». Разрабатываемый веб-магазин битов и драмкитов. На этапе недель 3–5 работают каталог, поиск, карточки, варианты с ценами и прослушивание демо из PostgreSQL. Заказы, тестовая оплата и выдача лицензий относятся к следующим этапам.

Автор: Поладов Михаил Заурович, группа ПИ 31/1.

## Запуск приложения

Нужен Node.js 22.12 или новее и npm 10 или новее. Проверено с Node.js 26.11.1 и npm 11.20.0 на Windows x64.

```powershell
npm ci
npm run demo
```

Открыть [Beatstore](http://127.0.0.1:3000). Команда demo применяет миграции, создаёт тестовые товары и материалы, проверяет типы, собирает и запускает приложение. Повторный запуск не создаёт дубликатов. После подготовки можно запускать `npm start`; остановка — Ctrl+C.

Проверка состояния: [health](http://127.0.0.1:3000/api/health). Без `DATABASE_URL` запускается локальный PostgreSQL 17.10; файлы базы и сгенерированный пароль хранятся в исключённой из Git `.local`. Отдельный PostgreSQL подключается через `DATABASE_URL` в `.env`. Пример: [.env.example](.env.example). На Windows для локального PostgreSQL нужны ASCII-пути либо доступные короткие имена 8.3. Подробности: [запуск и демонстрация](reports/sprint-03-05/demo.md).

Сервер: TypeScript и Express 5.3.0. Веб-интерфейс: React 19.3.1 и Vite 8.3.5. Точные версии всех зависимостей закреплены в `package-lock.json`. Docker для локального запуска не требуется.

## Разработка и проверки

```powershell
npm run db:migrate
npm run db:seed
npm run dev
```

В разработке клиент находится на [127.0.0.1:5173](http://127.0.0.1:5173), API — на порту 3000. В собранном приложении оба доступны на порту 3000. Материалы каталога — собственные синтетические демо; коммерческие лицензии ещё не подготовлены.

```powershell
npm test
npm run build
npm run test:e2e
```

Проверки БД и API используют реальные PostgreSQL и HTTP в изолированных схемах. Браузерные проверки требуют установленных Chrome и Edge и выполняются на ширинах 360 и 1280 пикселей. [Результаты](reports/sprint-03-05/verification.md), [API](reports/sprint-03-05/api.md), [схема БД](database/README.md).
